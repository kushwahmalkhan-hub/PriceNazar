📥 बहुत सारे Products एक साथ (Bulk Import)

CSV या JSON फ़ाइल चुनें। पुरानी Backup JSON फ़ाइल भी यहीं Restore होती है।
• CSV में पहली लाइन header होनी चाहिए: name, category, description, price, image, amazonLink, flipkartLink, searchTerms, display, processor, ram, storage, camera, battery, charging, rating (सिर्फ़ name ज़रूरी है)।
• Specs भरने के लिए: CSV में id के साथ सिर्फ़ ये कॉलम रखें: id, display, processor, ram, storage, camera, battery, charging, rating। उसी id के प्रोडक्ट में specs जुड़ जाएँगे, बाकी जानकारी वैसी ही रहेगी।
• id के बिना फ़ाइल हर बार नए products जोड़ती है, इसलिए एक ही फ़ाइल दो बार import न करें।
• id वाली फ़ाइल (Backup) उसी id के पुराने product को बदल देती है।
